# Agent guide

This repository distributes Agent Skills and Spec Kit components. Read `docs/architecture.md` before changing component boundaries and `docs/distribution.md` before changing manifests, catalogs, or release automation.

When editing a `SKILL.md` or command prompt, preserve one clear execution sequence, checkable completion criteria, and progressive disclosure. Keep durable policy in one owner and link to it rather than copying it.

Run clean-project installation checks for every changed extension or workflow. Do not report a release as ready until catalogs, manifests, packaged roots, and README commands agree on the same version.
