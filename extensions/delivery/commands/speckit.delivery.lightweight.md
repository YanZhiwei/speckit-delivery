# Lightweight Delivery

## Input

```text
$ARGUMENTS
```

Fix the live base/head scope and confirm the requested outcome is mechanical, documentation-only, or behavior-preserving. If requirements, public behavior, compatibility, durable data, security, or architecture are unclear, stop and recommend Feature or Bugfix instead.

Implement the narrow change, preserve unrelated user work, and run the smallest credible local check. Report changed paths, result, risk, and any reason the lane must escalate. The command is complete when the requested small outcome is visible and its targeted evidence passes.
